# Vuexy - Vue.js 3 Admin Dashboard Template

Vuexy Vue 3 version with Vuetify & Vite.

## Folder Structure

- `javascript-version/`
  - `full-version/`: Complete Vue 3 JavaScript admin dashboard with all features, apps, and pages.
  - `starter-kit/`: Minimal Vue 3 JavaScript starter template for starting a new project.
- `typescript-version/`
  - `full-version/`: Complete Vue 3 TypeScript admin dashboard.
  - `starter-kit/`: Minimal Vue 3 TypeScript starter template.

## Getting Started

1. Navigate to the project directory you want to run (e.g., `cd javascript-version/full-version`).
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
